# 🌸 Iris Dataset — EDA & Preprocessing

## Objective
Exploratory Data Analysis and preprocessing on the classic Iris dataset.

## Dataset
- 150 rows, 4 features + 1 target (species)
- Source: sklearn / UCI ML Repository

## What I did
- Checked shape, dtypes, missing values, duplicates
- Visualized distributions and correlations
- Wrote markdown cells explaining every step

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
