# Student Performance EDA

Exploratory Data Analysis on Student Performance dataset from Kaggle.

## What I did

- Analyzed impact of gender, parental education, test prep, lunch type and race/ethnicity on scores
- Created Total_marks feature combining all 3 subject scores
- Performed univariate and bivariate analysis across all categorical features

## Key Findings

- Females score higher in reading and writing, males score higher in math
- Students who completed test prep scored 23 marks higher on average (7.6% improvement)
- Parental education strongly impacts scores — master's degree parents have highest scoring students
- Standard lunch students score 26 marks higher than free/reduced lunch students
- Group E students score highest, Group A lowest — 29 point gap

## Tools

Python, Pandas, Matplotlib, Seaborn
